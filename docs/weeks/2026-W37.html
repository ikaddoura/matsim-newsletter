Core und Simulation (matsim-libs)

  • ZIP in IOUtils: ZIP kommt als fünftes Einzeldatei-Format neben gzip, lz4, bz2 und zst hinzu. Eine Datei entspricht einem ZipEntry mit dem Basisnamen, z.B. wird aus output_plans.xml.zip der Eintrag output_plans.xml. Es ist keine neue Abhängigkeit nötig, da java.util.zip genutzt wird. PR #5163
  • DSim: Die Abhängigkeit fory und der gesamte Serialisierungscode wandern in den Contrib "distributed simulation". Den Contrib braucht man nur, wenn man auf mehreren Rechenknoten simuliert. PR #5167
  • Refactoring: Für decideOnCoordForActivity gibt es eine Überladung ohne Scenario. PR #5169
  • Neu offen: Netzwerk-Tools für Infrastrukturklassifizierung und Höhendaten im Bicycle-Contrib, mit OSM- und SUMO-Pfad. PR #5168

Episim

  • Upgrade auf MATSim 2026 / Java 25: Dazu gehören aktualisierte Abhängigkeiten, die Anpassung an API-Änderungen, die Migration von Tests auf JUnit 5 und eine aktualisierte CI-Konfiguration. Zudem wird die Reflection auf SplittableRandom ersetzt, die durch die strengere Kapselung blockiert ist. PR #124
  • Batch-Output-Packing: Neue Tools verpacken einen fertigen Episim-Lauf für den covid-sim.info-Visualiser, der auf ein ZIP-basiertes Eingabeformat umgestellt wurde. Es kommen nur neue Klassen hinzu, bestehender Simulationscode bleibt unberührt. PR #125

Sonstiges

  • Neues Issue in vsp-internal: Der Python-SrV-Reader soll auch SrV 2018 und 2023 lesen können, die sich unterscheiden. Issue #10
  • In pt2matsim gab es 3 Commits, alle von Bots. Zusätzlich wurden 5 Bot-PRs gemergt, vermutlich Dependency-Updates.
