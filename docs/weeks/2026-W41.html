Bugfixes (DSim)

  • Scoring ohne Events: Der BackpackDataCollector registrierte Agenten erst beim ersten ActivityEndEvent. Agenten, die ihre erste Aktivität nie beenden, wurden daher nicht gescort (siehe Issue #5199). Sie werden nun über das neue Interface NotifyAgentInsertion registriert. PR #5206
  • Abfahrtsreihenfolge: Ein Comparator führte faktisch zu einer Sortierung nach ID. Das verursachte laut Beschreibung stark verspätete ÖV-Fahrzeuge in Berlin-Läufen mit DSim. Der Comparator wurde korrigiert. PR #5201

Neue Features

  • Remote-Operator-Extension für DRT: Das neue Paket remoteoperations in der operations-Extension von drt-extensions ergänzt die bestehende Driver-Shift-Infrastruktur. Die Schichten der Operatoren definieren eine aggregierte Überwachungskapazität, es gibt keine feste Zuordnung von Operator zu Fahrzeug. Damit lassen sich autonome Flotten mit Fernüberwachung modellieren. PR #5170
  • Kommerzielles Scoring: Der Grenznutzen von Ausführen und Warten wird aus dem Fahrzeugtyp des jeweiligen kommerziellen Agenten abgeleitet. Grenzaktivitäten werden nur noch gescort, wenn ihre Dauer vollständig definiert ist. PR #5141
  • Influenza in Episim: Unterstützung für Multi-Saison-Influenza-Szenarien mit mehreren Stämmen unter einem Erreger. Dazu kommen ein Infektiositätsprofil (infectivityProfile), Korrekturen beim Schreiben und Wiedereinlesen der Config sowie Batch-Output für Cluster. Bestehende Szenarien bleiben unverändert, solange das Profil nicht konfiguriert ist. PR #128

Infrastruktur und Doku

  • Die CONTRIBUTING.md enthält jetzt Richtlinien für plattformunabhängige Tests und Commit-Nachrichten. PR #5203
  • Zeilenenden im Pseudosimulations-Test wurden korrigiert, damit der Windows-Build-Server nicht mehr fehlschlägt. PR #5202
  • Ein Bot-PR (Dependency-Update) wurde gemergt.
