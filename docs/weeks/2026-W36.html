Bugfixes

  • Netzwerk: TimeVariantLinkImpl speicherte Change-Events in einer TreeMap nach Startzeit. Ein zweites Event auf demselben Link zur selben Sekunde verdrängte das erste, und recalc() warf dann eine Exception, weil die erwartete Anzahl der Events nicht übereinstimmte. Jetzt bleiben alle Events erhalten (PR #5153).
  • Pseudosimulation: Das Skript quality-metrics.sh zählte mit grep -c Zeilen statt SpotBugs-Funde. Da SpotBugs das gesamte <BugCollection>-Element in einer Zeile schreibt, ergab jede Anzahl größer null den Wert 1. Jetzt werden die Funde korrekt gezählt (PR #5158).

Performance und Features

  • DRT: Performance-Tweaks für das Min-Cost-Flow-Rebalancing, dazu eine Obergrenze für die Distanz von Relocations (PR #5156).
  • DSim: Die IdleStrategy im Threadpool ist jetzt konfigurierbar. Hintergrund sind Probleme mit den DSim-Integrationstests. Vermutet wird, dass der BusyThreadpool beim Warten auf neue Tasks aktiv wartet (Busy-Spin). Das hatte auf Maschinen mit genügend CPU-Kernen die Performance deutlich verbessert (PR #5150).

Contribs

  • Pseudosimulation: Das Contrib hatte nur 2 Tests und etwa 9 % Zeilenabdeckung. Es wurde rehabilitiert, getestet, refaktoriert und beschleunigt (PR #5122).
  • Small-Scale-Traffic-Generation: Maintenance mit kleinerem öffentlichem API-Umfang, angepasster Benennung von Variablen und Methoden sowie zusätzlichen Kommentaren und Fragen (PR #5152).
